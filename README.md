# MecaniQA Automotive Tech

## Equipe: Porto Velho

## Contexto

Este repositório contém o desenvolvimento da atividade **OAT 1 – Compreensão e Baseline**, proposta pelo Programa de Trainee da MecaniQA Automotive Tech.

Nesta atividade, a equipe atua como o time de Ciência de Dados da MecaniQA com o objetivo de compreender o histórico de manutenções automotivas, realizar a limpeza e análise dos dados temporais e desenvolver modelos preditivos baseline para servir como referência nas próximas etapas do projeto. :contentReference[oaicite:2]{index=2}
